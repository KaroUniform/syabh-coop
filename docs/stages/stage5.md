# Этап 5. Смерть, подъём напарника, откат

## Критерии готовности (записаны до реализации, 2026-11-23)

Решения игроков (дизайн, вопрос 6): напарника можно поднять за 60 с; не
успел — респаун у лодки, вещи в трупе, труп лежит до ухода с острова;
фрагменты из трупа при отплытии возвращаются в тайники; погибли все — откат к
моменту прибытия на остров; сдаться раньше можно.

Автотест (сервер `-coopautotest -coopdebug -coopreviveseconds 15`):

1. Смерть игрока: вещи (кроме служебных `NoWeapon`/`Throw*`, как в игре) — в
   трупе; труп **не исчезает** через 300 с (`DespawnTimeInSeconds` трупа
   игрока — практически бесконечность); отплыть нельзя, пока кто-то мёртв.
2. Подъём: живой напарник у трупа (≤ 2.5 м, сервер проверяет ≤ 6 м) держит
   `G` 3 с → погибший встаёт на месте трупа, все вещи из трупа возвращаются
   ему, здоровье — половина, кровотечение остановлено, капкан снят, труп
   исчезает. Сервер проверяет: поднимающий жив, погибший мёртв, окно не вышло.
3. «Сдаться»: кнопка респауна на экране смерти → респаун у лодки прибытия со
   стартовым набором класса, труп остаётся (уже без подъёма), вещи в нём.
4. Окно подъёма (60 с, в тесте 15 с) вышло → погибший респаунится у лодки сам.
5. Фрагмент в трупе при отплытии возвращается в свой тайник (не теряется).
6. Погибли все → через ~6 с откат: остров загружается заново из состояния на
   момент прибытия (лут, тайники, счёт фрагментов, вещи/здоровье игроков на
   момент прибытия), все — у лодки прибытия. Статистика (смерти) не
   откатывается.
7. Регрессия этапов 1–4.

## Решения ведущего

- Подсказки: погибшему — «Partner can revive you: N s. Respawn = give up»;
  живому у трупа — «Hold [G] to revive NAME». Клавиша `G` в игре свободна.
- Труп — тот же предмет игры (`RagdollWithInventoryBehaviour`), его можно и
  обыскать как раньше: подъём вернёт то, что в трупе осталось.
- Повторный респаун при живом игроке сервер отбрасывает (`RequestRespawn`
  игры не проверял смерть).
- Снимок прибытия игрока — после восстановления/выдачи набора; лут — файл
  `<остров>Inv.xml`, который сервер пишет сразу после загрузки острова.
