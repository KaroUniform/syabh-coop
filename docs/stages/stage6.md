# Этап 6. Кампания переживает перезапуск сервера и отключения

## Критерии готовности (записаны до реализации, 2026-11-23)

Решение игроков: «сохранение кампании сразу: острова, вещи и счёт переживают
перезапуск сервера; игрока узнаём по имени» (узнаём по ключу установки
`CoopPlayerId.txt`, без него — по имени).

1. Сервер пишет состояние кампании в `SaveGames/<сервер>/CoopCampaign.txt`:
   шаблоны островов, текущий остров и откуда приплыли, какие острова уже
   созданы, опустевшие тайники каждого острова, число тайников, счёт
   фрагментов, время игры, вещи/здоровье/сытость/статистику каждого игрока
   (по ключу), выбранные классы. Пишет: при каждом отплытии, при отключении
   игрока, каждые 30 с в игре и при выходе.
2. Перезапуск сервера (тот же каталог установки) → лобби → кампания
   **продолжается** на том же острове (без генерации, если остров на диске);
   игроки появляются у лодки прибытия со своими вещами; счёт тот же; круг на
   `Centre` и тайники — как были.
3. Фрагмент в трупе на момент записи считается возвращённым в свой тайник
   (труп после перезапуска не восстанавливается — фрагмент не должен
   пропасть). Лут сундуков текущего острова — на момент записи.
4. Отключение игрока посреди острова: его вещи (и фрагменты) — в снимок, а не
   «фрагменты в тайники»; при возвращении (в той же сессии или после
   перезапуска) он получает их обратно. Снимок отключившегося не стирается
   следующими отплытиями (ревью Kimi п.3).
5. Новая кампания: после победы — автоматически; вручную — чат
   `#coop newcampaign` (админ или любой игрок, если сервер без админа) или
   флаг сервера `-coopnewcampaign`.
6. Откат «все погибли» после записи на диск работает как раньше (лут
   прибытия хранится отдельной копией `<остров>Inv.arrival.xml`).
7. Регрессия этапов 1–5.

Автотест — два запуска сервера подряд на одной копии игры:
`-coopautotest6a` (дойти до North, взять фрагменты, B выходит из игры,
сервер записывает и выходит) и `-coopautotest6b` (проверить всё
восстановленное, сплавать North → Centre).

## Прогон автотеста (этап 6)

s6b продолжает то, что записал s6a, — запускать подряд на одной копии `run/mp`.

```bash
tools/test_coop.sh -n s6a -t 900 -S "-coopautotest6a -coopdebug" -A "-coopautotest -coopclass 1" -B "-coopbot -coopclass 2" -e "server:TEST DONE"
```

```bash
tools/test_coop.sh -n s6b -t 900 -S "-coopautotest6b -coopdebug" -A "-coopautotest -coopclass 1" -B "-coopbot -coopclass 2" -e "server:TEST DONE" -x "server:TEST FAIL"
```
