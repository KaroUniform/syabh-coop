# Этап 4. Свой класс у каждого игрока

## Критерии готовности (записаны до реализации, 2026-11-23)

1. Каждый игрок выбирает класс сам; выбор запоминается на его компьютере
   (`SaveGames/client/CoopClass.txt`) и действует во всех следующих играх.
2. Сервер выдаёт стартовый набор **класса владельца тела** (в начале кампании
   и при респауне), а не общий класс сервера
   (`C_PlayerEquipmentController.cs:91`). Автотест: A — класс 2 (индекс 1), B —
   класс 3 (индекс 2), у каждого в начале кампании ровно набор своего класса
   (по именам предметов `C_PlayerClassLoadOuts.m_ClassLoadOuts[i].m_Items`).
3. Переход между островами класс не меняет и набор не выдаёт (этап 2).
4. Неверный номер класса от клиента отбрасывается сервером.

## Как выбрать (для игроков)

- В лобби вверху экрана — плашка «Co-op class: …» с кнопками `<` и `>`.
- В игре — чат `#coop class` (список классов) и `#coop class <номер>`;
  действует со следующего стартового набора (начало кампании, респаун).

Классов 7 (имена из ресурсов игры, `sharedassets0.assets`): The Aristocrat,
The Gamekeeper, The Inventor, The Officer, The Cook, The Artist, The Old Soak.
Что входит в набор каждого — в ресурсах; сервер пишет состав в журнал.
