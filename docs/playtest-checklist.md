# Чек-лист живой проверки (два MacBook)

Что автотест на одном Mac проверить не может: настоящая сеть между двумя
компьютерами, ручное управление, интерфейс, ощущения. Пройти по порядку,
отмечать, что не так (лучше — с временем, тогда найду в журнале).

Журналы: `sir_Data/output_log.txt` игры (или файл из ключа `-logFile`),
строки `[SYABH-COOP]`; сохранение кампании — `SaveGames/<сервер>/CoopCampaign.txt`.

## 0. Запуск
- [ ] Сервер у тебя, игра-клиент у тебя и у него, оба подключились.
- [ ] В лобби вверху — плашка «Co-op class: …», стрелками выбрали разные классы.
- [ ] Старт: у каждого набор своего класса.

## 1. Лодки и острова
- [ ] У лодки подсказка «[B] propose to sail to …»; у напарника — «[B] agree / [N] refuse».
- [ ] Отказ («N») — остаёмся; согласие — оба на новом острове у лодки прибытия.
- [ ] Пока один кровоточит / голоден / мёртв / ещё грузится — отплыть нельзя (сообщение).
- [ ] Вещи, патроны, здоровье, сытость, слоты быстрого выбора — те же после переезда.
- [ ] Открытый сундук на прошлом острове при возвращении — такой же.

## 2. Фрагменты и камни
- [ ] Фрагмент из тайника едет с тобой; тайник остаётся пустым.
- [ ] На каждом острове 5 тайников, на Centre один рядом с кругом.
- [ ] Сдача в круг на Centre: счёт растёт у обоих, «N of 25».
- [ ] Фрагмент нельзя выбросить и нельзя положить обратно в тайник (сообщение).

## 3. Смерть
- [ ] Погиб — у напарника «X is down! Hold [G] at the body…», у тебя отсчёт.
- [ ] Напарник держит G у тела ~3 с — встал на месте, вещи при тебе, полздоровья.
- [ ] Не подняли за 60 с — сам появился у лодки с набором класса; тело лежит с вещами, его можно обыскать.
- [ ] Кнопка Respawn раньше — то же («сдаться»).
- [ ] Погибли оба — через ~6 с остров заново, как при прибытии (вещи, тайники, счёт).
- [ ] Один сдался (Respawn), потом погиб второй — у первого появляется «Hold [G]…» у тела второго.
- [ ] Погиб в воде — после подъёма встаёт рядом с поднявшим, а не на дне.
- [ ] После подъёма: управление, камера, экран — нормальные (нет красного/чёрного экрана, камера не на земле).

## 4. Сохранение
- [ ] Сыграли, закрыли сервер, запустили снова → лобби → тот же остров, вещи и счёт на месте.
- [ ] Один вышел из игры посреди острова и зашёл снова — его вещи (и фрагмент) при нём.
- [ ] `#coop newcampaign` в чате — новая кампания с Centre (у админа сервера; если админа нет — у любого).
- [ ] Оба вышли посреди острова, сервер не закрывали, зашли снова — тот же остров, вещи и тайники на месте.
- [ ] Сервер запускать всегда с портом 44466: сохранение лежит в `SaveGames/server44466/`.

## 5. Лаги у роботов
- [ ] Где лагает: только рядом с роботами? В бою? Когда смотришь на них или отвернувшись?
- [ ] Помогает ли снизить тени/качество в настройках графики — это отделит графику от кода.
      У каждого робота свой источник света и ~14 частей с тенями: если лагает именно «рядом», первым делом — тени.
- [ ] Если хочется цифр: запустить игру с `-coopperf` — в журнал раз в 5 с пишутся кадры/с и число роботов рядом.

## Команды чата
- `#coop` — статус кампании; `#coop class` / `#coop class N` — класс;
  `#coop newcampaign` — начать заново.
