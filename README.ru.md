# SYABH Co-op Campaign

Любительский мод для **Sir, You Are Being Hunted**: сюжетная кампания **вдвоём**.
Пять островов, лодки, 25 фрагментов, каменный круг и финальная сцена — в
кооперативе.

[English version](README.md)

## Что нужно

- **macOS** и [CrossOver](https://www.codeweavers.com/crossover)
- В CrossOver — **Steam-версия игры для Windows**, сетевая версия **1.1.2**
  (обычная ветка Steam; её запускает кнопка *Multiplayer* в лаунчере)
- Оба игрока — **в одной локальной сети**

Проверено на двух Mac в домашнем Wi-Fi. Игра через интернет, Windows и
родная Mac-версия игры не проверялись.

## Установка (у обоих)

1. Скачайте `syabh-coop-<версия>.zip` из [Releases](../../releases) и
   распакуйте. Версия у обоих должна быть **одинаковая**.
2. Закройте игру.
3. Двойной щелчок по `install.command`. Если macOS не открывает: правый
   щелчок → Открыть → Открыть.

Установщик сам найдёт игру в CrossOver, сохранит оригинал и соберёт мод из
вашей копии игры (несколько секунд). Если не найдёт — попросит перетащить в
окно папку `…/SirYouAreBeingHunted/x64/multiplayer/sir_Data/Managed`.

## Запуск сервера (у одного)

Двойной щелчок по `server.command`. Откроется окно сервера, а в Терминале —
**адрес для подключения** (вида `192.168.1.23`). Отправьте его другу.

Сервер работает, пока открыто его окно; закрыть окно — остановить. Кампания
сохраняется, и следующий запуск `server.command` продолжит с того же острова.

## Подключение (оба, включая хозяина сервера)

1. Запустите сетевую версию игры.
2. **Direct connect** → введите адрес → **Connect**.
3. В лобби выберите класс кнопками `<` и `>`, затем **Ready**. Остров
   начнётся, когда готовы оба.

Если macOS спросит про входящие подключения — разрешите. В гостевой сети Wi-Fi
устройства обычно друг друга не видят.

## Как играть

- **Отплытие:** у лодки **B** — предложить или согласиться, **N** —
  отказаться. Нельзя, пока кто-то кровоточит, голоден или мёртв.
- **Фрагменты и вещи** переезжают с вами между островами.
- **Смерть:** подойдите к телу напарника и держите **G** 3 секунды (в течение
  60 с). Не успели — он появится у лодки, вещи останутся в теле. Погибли оба —
  остров начнётся заново с момента прибытия.
- **Чат:** `#coop` — состояние кампании. Хозяин сервера может начать заново:
  `#coop newcampaign`.

## Удаление

Двойной щелчок по `restore.command` или Steam → Свойства игры → Установленные
файлы → Проверить целостность. Обновление игры в Steam тоже убирает мод —
поставьте заново.

## Если что-то не так

- **Сервер не пускает из-за версии клиента:** у кого-то нет мода или другая
  версия. Поставьте один и тот же архив на оба Mac.
- **Установщик отказывается:** игра не сетевая 1.1.2 или файл уже изменён.
  Проверьте целостность в Steam и запустите снова.
- **Журналы:** строки мода начинаются с `[SYABH-COOP]`. Клиент —
  `x64/multiplayer/sir_Data/output_log.txt`, сервер —
  `x64/multiplayer/server-log-44466.txt`.

## Разработчикам

Мод — патч [MonoMod](https://github.com/MonoMod/MonoMod) к
`Assembly-CSharp.dll` игры, исходники в `src/SyabhCoop/`. Для сборки нужны Mono
(`brew install mono`) и игра; дальше — `tools/get_monomod.sh`,
`tools/build_mod.sh` и `tools/make_dist.sh`. Каждый шаг описан в начале
скрипта.
